## Technical debt accepted for milestone completion

The generated client under `src/app/api/` proves repeatable OpenAPI generation and CI drift enforcement, satisfying `FOUND-06` and `CI-04`. It is not yet the SPA's runtime contract: handwritten feature services still use `HttpClient`, and minimal endpoint metadata yields `void` for many generated responses. This is non-blocking for the literal v1.0 requirement but should be addressed before migrating feature services to the generated client.

The v1.1 and v2 deferrals listed in the frontmatter are deliberate future scope, not incomplete v1.0 work.

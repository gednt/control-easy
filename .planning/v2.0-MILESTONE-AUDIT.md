### Forward-compatible shims (technical debt, not blockers)

1. **Photos entity binding** — Phase 12 ships `PhotoBindingCacheService` (localStorage) because backend Photos table lacks `entity_type` + `entity_id` columns. When backend ships migration, swap to `photosApi.list()`.

2. **Thumbnail route** — Phase 12 uses CSS `object-fit: cover` on source URL because backend lacks `GET /api/v1/photos/{id}/thumbnail`. When backend ships the route, swap to dedicated thumbnail URL.

3. **Consent policy list** — Phase 13 calls `/consent-policy/{category}` 4× in parallel because backend lacks `GET /consent-policy` (list). When backend ships the list endpoint, swap to single call.

4. **Pagination total** — Phase 13 audit uses `entries.length` for pagination display because backend doesn't return X-Total-Count header. When backend ships the header, read it for accurate pagination.

These are documented inline at each affected code site (`// Phase 12/13 deviation:` comments) and in each VERIFICATION.md.

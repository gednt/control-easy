# Phase 11 Plan — Photos & Consent Schema Infrastructure

> **Note:** This plan was backfilled retrospectively after the phase shipped in commit `d895c01`. It documents the actual shipped implementation, not a forward-looking plan. Created 2026-09-12 to bring Phase 11 into GSD conformance.

## Goal

Storage abstraction, database schema for photos and consent audit log, tenant consent policy config, upload/retrieve/delete endpoints with permission gates.

## Plan 11-01: Photos & Consent Schema Infrastructure (Shipped in `d895c01`)

### Tasks

1. **Module scaffold** — `src/Modules/Photos/` with `Domain`, `Application`, `Infrastructure`, `Api` layers (Clean Architecture)
2. **Domain entities** — `Photo`, `ConsentAuditLog`, `TenantConsentPolicy`, enums `EntryState`, `OverrideReason`
3. **Storage abstraction** — `IStorageProvider` interface + three implementations:
   - `LocalFilesystemStorageProvider` (dev)
   - `S3StorageProvider` (MinIO-compatible, uses MinIO endpoint)
   - `AmazonS3StorageProvider` (native AWS S3, uses AWSSDK.S3)
4. **Database schema** — migrations for `photos`, `consent_audit_log`, `tenant_consent_policy` tables
5. **Append-only triggers** — DB triggers on `consent_audit_log` to reject UPDATE/DELETE
6. **CHECK constraint** — `entered_with_consent` requires `photo_id NOT NULL`
7. **Handlers**:
   - `UploadPhotoHandler` (validates mime, size, stores via IStorageProvider)
   - `GetPhotoHandler` (returns source stream)
   - `SoftDeletePhotoHandler` (sets deleted_at)
   - `CreateEntryLogHandler` (validates policy, enforces state transitions)
   - `ListEntryLogsHandler` (with filters)
   - `ExportEntryLogCsvHandler` (millisecond-precision recorded_at)
   - `UpdateConsentPolicyHandler`
8. **Endpoints** — minimal API endpoint classes in `PhotosEndpoints.cs`, `EntryLogEndpoints.cs`, `ConsentPolicyEndpoints.cs`
9. **Permissions** — `photos.read`, `photos.write`, `photos.delete`, `consent.read`, `consent.write`, `entry-log.create`, `entry-log.read`, `entry-log.export`
10. **Tests** — 118 unit + 73 integration covering cross-tenant isolation, append-only triggers, CHECK constraint, policy enforcement, CSV export formatting, storage provider round-trip, permission gates
11. **Docker** — added MinIO service to `docker/docker-compose.yml`; MinIO seed in `docker/docker-compose.demo.yml`
12. **Configuration** — `STORAGE__PROVIDER`, `STORAGE__LOCAL__PATH`, `STORAGE__S3__*` env vars

# Quickstart: Dashboard Visits and Access Registration

1. Start the project through the Docker Compose stack for this worktree.
2. Sign in as a gatehouse-authorized user and open the dashboard.
3. Select **Add visit**, complete visitor details, select an apartment, and save. Confirm the visit and its apartment appear in the Visits page.
4. On the dashboard select **Record access**, choose **Register entry**, choose Resident or Vehicle, and save the movement. Confirm it appears in audit history.
5. Select **Record access**, choose **Register exit**, choose Resident or Vehicle, and save. Confirm the audit history labels it Exit.
6. Verify the audit filter can show Exit events and that an attempt to submit an exit for a visitor or service provider is rejected.

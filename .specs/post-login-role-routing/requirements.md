# Tenant-Scoped Access — Requirements

## User stories

- **UC-1:** As a **porteiro** or **tenant admin**, I want to see only the condominium I belong to so I never operate on another building's data.
- **UC-2:** As a **multi-condominium user**, I want to switch only between condominiums where I have an active profile, not the full platform list.
- **UC-3:** As a **Platform Admin (system admin)**, I want to land on the platform condominiums screen and manage all tenants without being dropped into a single building's portaria UI.
- **UC-4:** As any signed-in tenant user, I want the current condominium name visible in the shell so I always know which building I am working in.

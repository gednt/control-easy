ControlEasy Reborn — Design System Mockup

Reference-driven visual foundation for the Angular SPA. Implements every base component from .specs/2 - visual-design-system/.

Welcome to the mockup

This is a self-contained, build-free prototype of the design system. Every color, radius, shadow, and animation comes from the same CSS custom property tokens that the Angular app will use. Switch the theme using the topbar sun/moon button to verify the dark theme; the data-theme attribute on <html> drives everything.

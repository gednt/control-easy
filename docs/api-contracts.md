## Key Endpoints (non-exhaustive)

### Auth
- `POST /api/v1/security/auth/login` — `{ email, password }` → `{ accessToken, refreshToken, tenantId, profileId, roles, permissions }`
- `POST /api/v1/security/auth/refresh` — `{ refreshToken }` → new token pair (rotation)
- `GET  /api/v1/security/session` — current user/tenant/roles/permissions
- `POST /api/v1/security/auth/change-password` — post-bootstrap password change

### Bootstrap
- `GET  /api/v1/security/bootstrap` — exposes one-time `PlatformAdmin` email/password to E2E on first boot

### Tenants
- `GET  /api/v1/tenants` — list (PlatformAdmin)
- `POST /api/v1/tenants` — create (PlatformAdmin)
- `POST /api/v1/admin/tenants/{id}/suspend` / `/resume` (PlatformAdmin)
- `POST /api/v1/admin/backups` — trigger `TenantBackupService` (mysqldump + gzip)

### Residents
- `GET  /api/v1/residents?skip=&take=&search=` — paged list
- `GET  /api/v1/residents/{id}`
- `POST /api/v1/residents` — `CreateResidentHandler`
- `PUT  /api/v1/residents/{id}` — `UpdateResidentHandler`
- `DELETE /api/v1/residents/{id}` — soft-delete

### Apartments
- `GET  /api/v1/apartments?block=&unit=`
- `POST /api/v1/apartments`
- `PUT  /api/v1/apartments/{id}` — also handles inline resident management (Phase 6)

### Visits
- `GET  /api/v1/visits/open` — list of open visits
- `POST /api/v1/visits/{id}/checkin` / `/checkout`

### Vehicles, ServiceProviders — CRUD per established pattern

### Reports (CQRS-lite)
- `GET  /api/v1/dashboard/stats` — `GetDashboardStatsHandler` (currently in-memory aggregation; see CONCERNS)
- `GET  /api/v1/reports/visits-by-day` — `GetVisitCountsByDayHandler`

### Demo
- `POST /api/v1/demo/reset` — wipes and re-seeds demo data (PlatformAdmin only)

### Feature Flags
- `GET  /api/v1/features` — current flag state (used by Angular to decide route)

## Request/Response Conventions

- **Request bodies:** `sealed record` DTOs in `Application/Contracts/`. `Create*Request`, `Update*Request`, `*Query` (for GETs).
- **Response bodies:** `sealed record` response DTOs. `*Response` records with positional parameters.
- **Pagination:** `?skip=&take=` (not page/size). `ReportReadRepository` uses `.Take(10)` for dashboard.
- **Search:** Free-text `?search=` parameter; LIKE-based for residents.
- **Error format:** RFC 7807 `ProblemDetails` with `errors` extension dictionary for validation failures.

## Cross-Cutting Auth Headers

- `Authorization: Bearer {accessToken}` — required on all non-public endpoints.
- JWT claims: `tenant_id` (Guid), `profile_id` (Guid), `roles[]`, `permissions[]`.
- Tenant resolution: `TenantResolutionMiddleware` reads claim → `ITenantContext` → all tenant-scoped repositories.

## How to Find an Endpoint's Handler Chain

1. Find `Endpoints/{Entity}Endpoints.cs` in the module's `Api` project.
2. The endpoint method delegates to a handler injected via `IServiceProvider`.
3. Handler is in `Modules/{Module}/Application/Handlers/{Verb}{Entity}Handler.cs`.
4. Validator in `Application/Validators/{Request}Validator.cs`.
5. Repository in `Modules/{Module}/Infrastructure/Persistence/{Entity}Repository.cs`.
6. Tenant filter is applied via `TenantAwareLinqFactory.Create(_ctx)`.

## OpenAPI / TypeScript Client

- **Server:** `Swashbuckle.AspNetCore 6.6.2` exposes Swagger UI at `/swagger` in Development. `Program.cs` registers the middleware.
- **Client generator:** `ng-openapi-gen 1.0.5` configured in `ng-openapi-gen.json`. Output target: `src/Web/ControlEasyReborn.Web/src/app/api/`.
- **Current state (gap):** Generation is **not** part of the Docker web build. `src/app/api/` does not exist; every feature ships a manual `*-api.service.ts` with hand-maintained DTOs. Migration to generated client is **not yet started** — see `REQUIREMENTS.md` (CI-04) and `CONCERNS.md` (hand-written clients).
- **Run command (local):** `cd src/Web/ControlEasyReborn.Web && npm run openapi-gen` (against a running API).

## Endpoint Audit (where to add tests)

Every new endpoint should add:
1. Unit test in `tests/ControlEasyReborn.UnitTests/Modules/{Module}/{Handler}Tests.cs`.
2. Validator test in `tests/ControlEasyReborn.UnitTests/Modules/{Module}/{Validator}Tests.cs`.
3. Integration test in `tests/ControlEasyReborn.IntegrationTests/{Module}EndpointTests.cs` (Testcontainers MySQL).
4. At least one `CrossTenant_*` test if the endpoint touches a repository (enforced by `CrossTenantTestNamingTests`).
5. Playwright E2E in `src/Web/ControlEasyReborn.Web/e2e/` for user-facing CRUD flows.
